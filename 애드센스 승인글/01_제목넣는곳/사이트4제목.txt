카테고리 1: 프롬프트 기본 원리와 구성
카테고리 설명:
프롬프트가 어떤 구조로 이루어지는지 기본 개념부터 살펴봅니다.
목적, 맥락, 조건, 출력 형식 등 요청문을 구성하는 핵심 요소를 다룹니다.
좋은 요청과 모호한 요청의 차이를 비교하며 작성 원리를 익힙니다.

세부 카테고리 1-1: 프롬프트의 핵심 구성 요소
세부 카테고리 설명:
프롬프트를 구성하는 목적, 역할, 맥락, 조건, 결과 형식의 차이를 살펴봅니다.
각 요소가 결과의 방향에 어떤 영향을 주는지 이해할 수 있습니다.

1. 여행 일정표를 요청할 때 목적과 조건을 구분하는 프롬프트 작성 사례
2. 초등학생 과학 설명에서 AI의 역할을 지정하는 프롬프트 구성 예시
3. 신입사원 업무 안내문에 필요한 배경 정보를 전달하는 프롬프트 설계
4. 가족 여행 계획에서 예산과 이동 시간을 조건으로 설정하는 프롬프트
5. 회의 결과 정리에서 핵심 결정사항을 추출하는 프롬프트 구성 사례
6. 온라인 쇼핑 상품 설명에 구매 대상과 사용 목적을 반영하는 프롬프트
7. 요리 레시피 요청에서 재료와 조리 도구를 구분해 전달하는 방법
8. 독서 감상문 작성에서 책 정보와 독자 수준을 설정하는 프롬프트 예시
9. 운동 계획표를 만들 때 목표와 실행 조건을 함께 제시하는 프롬프트
10. 지역 행사 안내문에서 장소와 일정 정보를 구조화하는 프롬프트 사례

세부 카테고리 1-2: 명확한 요청문 만들기
세부 카테고리 설명:
같은 의도라도 표현이 모호하면 결과가 달라질 수 있는 요청문을 다룹니다.
구체적인 표현과 질문 방식으로 원하는 작업을 전달하는 방법을 익힙니다.

11. ‘맛집 추천해 줘’를 예산과 음식 종류가 있는 요청문으로 바꾸는 방법
12. ‘이메일 작성해 줘’를 거래처 일정 변경 안내문으로 구체화하는 사례
13. ‘공부 계획 세워 줘’를 시험일까지의 주간 학습표 요청으로 바꾸기
14. ‘좋은 제목 만들어 줘’를 독자와 글 주제가 분명한 요청으로 수정하기
15. ‘여행 준비 알려 줘’를 목적지와 계절에 맞는 준비물 목록으로 바꾸기
16. ‘자료 정리해 줘’를 날짜별 업무 보고서 요청으로 명확하게 작성하기
17. ‘쉽게 설명해 줘’를 중학생 대상 과학 설명으로 구체화하는 방법
18. ‘상품 비교해 줘’를 가격과 주요 기능 중심의 비교 요청으로 바꾸기
19. ‘문장 고쳐 줘’를 맞춤법과 어색한 표현 수정 요청으로 명확히 만들기
20. ‘아이디어 추천해 줘’를 소규모 동호회 행사 기획 요청으로 바꾸기

세부 카테고리 1-3: 출력 결과 설계하기
세부 카테고리 설명:
프롬프트 단계에서 결과물의 형태와 구성 방식을 미리 설계하는 방법을 다룹니다.
목록, 표, 단계별 설명, 요약 등 목적에 맞는 출력 방식을 지정하는 법을 알아봅니다.

21. 일주일 식단을 요일별 표로 출력하도록 요청하는 프롬프트 사례
22. 여행 준비물을 의류와 전자기기로 나눈 체크리스트 작성 요청법
23. 회의록을 결정사항과 담당자별 할 일로 구분하는 출력 형식 설계
24. 도서 추천 결과를 제목과 저자와 추천 이유로 정리하는 프롬프트
25. 월간 지출 내역을 항목별 금액과 합계 표로 정리하는 요청 사례
26. 제품 사용 설명서를 준비·설치·점검 순서로 작성하는 프롬프트
27. 온라인 강의 내용을 핵심 개념과 복습 질문으로 나누는 출력 설계
28. 블로그 글 초안을 도입·본문·마무리 구조로 작성하는 프롬프트
29. 고객 문의 답변을 인사·안내·후속 조치 순서로 구성하는 요청법
30. 프로젝트 진행 현황을 완료·진행 중·예정 항목으로 구분하는 프롬프트

==========================================

카테고리 2: 프롬프트 작성 전략과 질문 설계
카테고리 설명:
프롬프트의 목적에 맞게 질문을 설계하고 요구사항을 단계적으로 전달하는 방법을 다룹니다.
복잡한 작업을 작은 단위로 나누고, 필요한 정보를 효과적으로 제공하는 전략을 살펴봅니다.
질문의 순서와 표현을 조정하면서 결과의 일관성을 높이는 방법을 알아봅니다.

세부 카테고리 2-1: 작업을 단계로 나누는 방법
세부 카테고리 설명:
복잡한 요청을 여러 단계의 작업으로 분리하는 프롬프트 설계 방식을 다룹니다.
작업 순서를 명확하게 제시해 결과물이 체계적으로 만들어지도록 하는 방법을 알아봅니다.

31. 신제품 출시 계획을 시장 조사부터 홍보 일정까지 단계별로 요청하는 프롬프트
32. 해외여행 준비를 항공권·숙소·현지 일정으로 나누어 설계하는 프롬프트 사례
33. 온라인 쇼핑몰 개설 과정을 상품 선정부터 판매 페이지 작성까지 나누는 방법
34. 자격증 시험 준비를 학습 범위 분석과 주간 복습 계획으로 분리하는 프롬프트
35. 회사 워크숍 기획을 장소 선정·프로그램 구성·예산 검토로 나누는 요청법
36. 이력서 작성과 자기소개서 수정을 별도 단계로 진행하는 프롬프트 설계
37. 동호회 소식지 제작을 자료 수집·원고 작성·최종 검토로 구분하는 방법
38. 가정 이사 준비를 물품 분류·포장·주소 변경 순서로 요청하는 프롬프트
39. 소규모 전시회 준비를 작품 선정부터 방문객 안내까지 단계화하는 요청 사례
40. 온라인 강좌 제작을 교육 목표·차시 구성·평가 문제 순서로 설계하는 프롬프트

세부 카테고리 2-2: 질문의 관점과 조건 설정
세부 카테고리 설명:
같은 주제를 서로 다른 관점에서 질문하고 필요한 조건을 구체화하는 방법을 다룹니다.
비교, 설명, 분석, 아이디어 발상 등 목적에 따라 질문의 방향을 설정하는 법을 익힙니다.

41. 노트북 구매를 대학생과 영상 편집자의 관점에서 비교하도록 질문하는 방법
42. 카페 창업 아이디어를 고객 편의와 운영 비용 관점으로 나누는 프롬프트
43. 대중교통 개선안을 이용자와 교통 운영자의 입장에서 분석하는 요청 사례
44. 어린이 도서 추천에서 연령·독서 수준·관심 분야를 조건으로 설정하는 방법
45. 재택근무 장단점을 직원과 관리자 관점에서 비교하는 프롬프트 설계
46. 반려동물 용품을 가격·관리 편의성·내구성 기준으로 비교하는 요청법
47. 지역 축제 홍보 아이디어를 주민과 관광객의 관점에서 각각 요청하는 방법
48. 외국어 학습법을 초급 학습자와 중급 학습자의 목표에 맞춰 비교하는 프롬프트
49. 친환경 포장재를 비용·재활용 가능성·사용 편의성 기준으로 평가하는 질문
50. 독서 모임 운영 방안을 참여율과 토론의 질이라는 두 관점에서 분석하는 요청법

세부 카테고리 2-3: 맥락과 참고 정보 활용
세부 카테고리 설명:
AI가 작업의 배경과 요구사항을 이해할 수 있도록 맥락과 참고 정보를 제공하는 방법을 다룹니다.
불필요한 정보와 필요한 정보를 구분해 효율적인 프롬프트를 구성하는 방법을 알아봅니다.

51. 고객 상담 기록을 참고해 후속 안내 이메일을 작성하는 프롬프트 사례
52. 학교 가정통신문을 바탕으로 학부모용 일정 요약을 요청하는 방법
53. 제품 설명서의 기능 정보를 활용해 초보자용 사용 안내를 만드는 프롬프트
54. 식당 메뉴와 알레르기 정보를 제공해 음식 선택 기준을 정리하는 요청법
55. 지난달 매출 자료를 참고해 매장별 판매 현황을 설명하도록 요청하는 방법
56. 회의 안건과 참석자 역할을 제공해 토론 질문을 만드는 프롬프트 사례
57. 여행지 공식 안내문을 기준으로 운영시간과 입장 조건을 정리하는 요청법
58. 교육과정 자료를 제공해 학습 목표에 맞는 복습 문제를 만드는 프롬프트
59. 고객 설문 응답을 참고해 만족도와 개선 의견을 구분하는 질문 설계
60. 사내 업무 규정을 제공해 신규 직원용 업무 절차를 설명하는 프롬프트

==========================================

카테고리 3: 프롬프트 개선과 결과 품질 높이기
카테고리 설명:
처음 작성한 프롬프트의 결과를 살펴보고 부족한 부분을 개선하는 방법을 다룹니다.
원하는 결과와 실제 결과의 차이를 분석하고 요청문을 수정하는 과정을 살펴봅니다.
반복적인 수정 과정을 통해 보다 일관된 결과를 얻는 프롬프트 설계법을 알아봅니다.

세부 카테고리 3-1: 결과를 확인하고 수정하기
세부 카테고리 설명:
프롬프트를 실행한 뒤 결과에서 부족하거나 잘못된 부분을 찾아 수정하는 방법을 다룹니다.
결과를 기준으로 어떤 조건을 추가하거나 변경해야 하는지 판단하는 방법을 익힙니다.

61. 여행 일정표에서 이동 시간이 빠졌을 때 프롬프트를 수정하는 방법
62. AI가 작성한 거래처 이메일의 말투가 지나치게 딱딱할 때 개선하는 요청법
63. 블로그 글 초안에 소제목이 누락되었을 때 구조를 다시 요청하는 프롬프트
64. 일주일 식단표에 중복 메뉴가 많을 때 다양성을 높이는 수정 요청 사례
65. AI가 만든 학습 계획에서 휴식 시간이 빠졌을 때 보완하는 프롬프트
66. 제품 비교표에서 가격 정보가 불확실할 때 확인 항목을 추가하는 요청법
67. 회의 요약에서 담당자와 마감일이 누락되었을 때 수정하는 프롬프트
68. 자기소개서 초안에 실제 경험과 다른 내용이 포함되었을 때 바로잡는 방법
69. 관광지 안내문에서 운영시간 정보가 확인되지 않을 때 수정하는 프롬프트
70. AI가 작성한 행사 안내문의 날짜와 장소가 잘못되었을 때 검토하는 방법

세부 카테고리 3-2: 결과의 일관성과 정확성 높이기
세부 카테고리 설명:
반복해서 사용하는 프롬프트에서 결과의 형식과 방향을 일정하게 유지하는 방법을 살펴봅니다.
요구사항과 기준을 명확히 제시해 결과의 편차를 줄이는 방법을 알아봅니다.

71. 온라인 쇼핑몰 상품 설명 20개의 길이와 구성을 일정하게 유지하는 프롬프트
72. 매주 작성하는 업무 보고서에서 동일한 항목과 순서를 유지하는 요청법
73. 고객 문의 답변에서 확인되지 않은 배송 일정을 단정하지 않도록 하는 프롬프트
74. 초등학생 학습 문제를 만들 때 난이도와 정답 형식을 통일하는 방법
75. 블로그 글 제목 50개를 생성할 때 중복 표현을 줄이는 검토 조건 설정법
76. 여러 지점의 매출 보고서를 동일한 기간과 금액 단위로 정리하는 프롬프트
77. 제품 사용 안내문에서 기능 이름과 용어를 일관되게 사용하는 요청 사례
78. 독서 기록 카드 30개를 동일한 질문과 글자 수 기준으로 만드는 프롬프트
79. 음식 레시피에서 재료의 중량과 조리 시간을 일정한 형식으로 표시하는 방법
80. 교육용 퀴즈에서 정답과 해설이 서로 일치하는지 점검하도록 요청하는 프롬프트

세부 카테고리 3-3: 프롬프트 실험과 비교
세부 카테고리 설명:
